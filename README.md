# QuiltMath

The honest math of quilting: block grid and finished size, fabric yardage with seam allowance and waste, backing width check, binding strips, and the real materials total.

Static site. No build, no backend, no tracking. Open `index.html`.

- **Engine:** `engine.js` - pure functions, tested in Node.
- **App:** `app.html` - four cards (top, fabric, backing/binding, cost) with size presets.
